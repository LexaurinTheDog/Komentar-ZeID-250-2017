# Komentář k zákonu č. 250/2017 Sb., o elektronické identifikaci

Otevřený komentář k zákonu o elektronické identifikaci — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; prokázání totožnosti elektronickou identifikací, kvalifikovaný systém a správce, akreditace, povinnosti správce, držitele a poskytovatele, národní bod, evidence, působnost Digitální a informační agentury a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2017-00250_2023-04-01`.
